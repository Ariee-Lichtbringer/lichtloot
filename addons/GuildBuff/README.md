# GuildBuff

Raid-Buffcheck für WoW Classic Era: Übersicht nach Spieler und Gruppe, feste Buffeinteilung, Ablaufwarnungen, Erinnerung per Flüstern, Chatmeldung nach dem Buffen und Seelenstein-Leiste für Hexenmeister. Läuft komplett lokal, ohne GuildLoot-Account.

Öffnen: Startsymbol anklicken oder /gbuff. /gbuff plan öffnet die Buffeinteilung für den Raid, /gbuff symbol blendet das Startsymbol ein oder aus.

Alle Zauber laufen über feste sichere Buttons; das Addon wirkt nichts automatisch. Die Buffeinteilung wird per Addon-Nachricht mit anderen GuildBuff- und GuildLoot-Era-Nutzern im Raid geteilt.

Ist GuildLoot Era installiert, deaktiviert sich GuildBuff selbst, weil der Buffcheck dort bereits enthalten ist.
