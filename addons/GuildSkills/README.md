# GuildSkills

Berufsübersicht für WoW Classic Era: eigene Rezepte aller Charaktere auf dem Account, komplette Berufe-Datenbank mit Zutaten, Skillguides mit Materialplan und Mengenrechner. Läuft komplett lokal, ohne GuildLoot-Account.

Öffnen: Berufe-Symbol anklicken oder /gskills. /gskills symbol blendet das Symbol ein oder aus.

Ist GuildLoot Era installiert, deaktiviert sich GuildSkills selbst, weil die Berufsübersicht dort bereits enthalten ist. Die charübergreifende Speicherung auf GuildLoot gibt es nur mit GuildLoot Era und GuildLoot Sync.

Datenquellen und Lizenz der Berufsdaten: PROFESSION-DATA-SOURCE.txt und PROFESSION-DATA-LICENSE.txt.
