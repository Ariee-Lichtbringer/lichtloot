Raidsheets

Eine feste Google-Sheets-Adresse pro Raidtyp. Änderungen an Spielernamen und Zellen werden von GuildLoot Sync neu geladen. Der Link muss nicht jede Woche geändert werden.

Die Adressen sind für Spieler dieser Gilde in der Sync-App sichtbar. Für den automatischen Abruf muss das Sheet ohne Google-Anmeldung lesbar sein und den Export für Betrachter erlauben.

Mit Apps Script verbinden

Für angemeldete Google-Konten mit Zugriff auf das Sheet. Die Verbindung überträgt Tabelleninhalte und Zellfarben dieses Raidtyps an GuildLoot. Die Aufstellung ist danach für GuildLoot-Nutzer dieser Gilde abrufbar. Der Code darf nur im zugehörigen Apps-Script-Projekt gespeichert werden.

Oben die passende Sheet-Adresse und den Gildenleitungs-PIN eintragen. Ein neuer Code ersetzt den bisherigen Schlüssel dieses Raidtyps.

Im Apps-Script-Editor die Funktion guildLootConnect ausführen und den Verbindungscode im Eingabefenster einfügen. Google kann dafür die Berechtigung für eine regelmäßige Ausführung anfordern.
